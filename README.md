# Stable Sato Viewer

**Stable Sato Viewer** は、Stable Diffusion で生成された PNG 画像のメタデータ（プロンプト、ネガティブプロンプト、学習パラメータ）を表示・管理するための Windows デスクトップアプリケーションです。

![Stable Sato Viewer](PngViewer/Assets/stablesatoviewer.png)

[English README is here](README.en.md)

## 主な機能

- :file_folder: **フォルダツリー表示** - ドライブ全体を階層的に表示、フォルダ間を簡単に移動
- :framed_picture: **画像ビューア** - PNG 画像の表示と拡大縮小
- :mag_right: **マウス操作でズーム** - スクロール拡大/縮小、ドラッグパン、マウス中心ズーム、ウィンドウリサイズ対応
- :memo: **メタデータ表示** - PNG の tEXt/iTXt チャンクから情報を抽出・表示
  - プロンプト (Parameters)
  - ネガティブプロンプト (Negative Prompt)
  - 学習パラメータ (Steps、CFG Scale、Sampler など)
- :mag: **フィルター機能** - プロンプトの内容で画像を検索・絞込
- :star: **お気に入り管理** - よく使う画像をブックマーク
- :history: **履歴機能** - 開いた画像を履歴に記録、再表示可能
- :art: **レイアウトモード** - パネルに応じた表示切替
- :clipboard: **クリップボードコピー** - 選んだテキストをコピー
- :wastebasket: **ゴミ箱削除** - 不要な画像を安全に削除
- :floppy_disk: **状態保存** - ウィンドウサイズ、位置、最後に開いた画像を記録

## システム要件

- **OS**: Windows 10/11
- **.NET**: .NET 10.0 以上を推奨
- **その他**: WPF 対応

## インストール

### リリース版（推奨）

1. [Releases](https://github.com/satochan0112/stable-sato-viewer/releases) から最新版をダウンロード
2. ZIP ファイルを解凍
3. `StableSatoViewer.exe` を実行

### ソースからビルド

```bash
git clone https://github.com/satochan0112/stable-sato-viewer.git
cd stable-sato-viewer/PngViewer
dotnet build -c Release
```

## 使い方

### 画像の開き方

#### 1. フォルダツリーから選択

- 左側のフォルダツリーでフォルダを展開・選択
- 選択したフォルダ内の PNG 画像がファイル一覧に表示されます
- ファイル一覧から画像をシングルクリックで表示

#### 2. ドラッグ＆ドロップ

- PNG ファイルまたはフォルダを画像表示エリアにドラッグ＆ドロップ
- ファイルの場合：そのファイルを表示
- フォルダの場合：そのフォルダを開いて、フォルダ内の最初の PNG を表示

#### 3. コマンドライン引数

```bash
StableSatoViewer.exe "C:\path\to\image.png"
```

### 画像の切り替え

| 操作 | 結果 |
|------|------|
| `左` / `右` キー | 前の画像 / 次の画像 |
| マウスサイドボタン | XButton1（戻る）/ XButton2（進む）で画像を切り替え |
| ファイル一覧で選択 | シングルクリックで画像を表示 |

### ズーム機能

#### スクロールでズーム

- **マウスホイール上**: 拡大
- **マウスホイール下**: 縮小
- **ズーム範囲**:
  - 最小値：ウィンドウに画像全体がピッタリ収まるサイズ（ウィンドウが小さい場合は 100% 未満の場合もあります）
  - 最大値：500%
- 拡大/縮小は段階的（各スクロール段階で約 10% ずつ変更）

#### マウス位置中心ズーム

- スクロール時、マウスカーソルがある箇所を中心にズーム
- 直感的に見たい部分を拡大できます

#### ドラッグ＆パン

- 画像が拡大された状態（最小値より大きい場合）で、ドラッグして見える範囲を移動
- 拡大後の詳細確認に便利

#### ウィンドウリサイズ対応

- ウィンドウをリサイズすると、新しいウィンドウサイズに合わせてズームが自動的にリセット
- ズーム情報がクリアされ、新しいウィンドウサイズでの最小値が適用されます
- ウィンドウが小さい場合でも、画像全体を見ることができます

#### ウィンドウタイトルに拡大率表示

- ウィンドウタイトルに「Zoom: 100%」などの形式で現在のズーム率を表示
- 拡大/縮小の目安として確認可能

### メタデータの表示

画像を開くと、右側のパネルに以下の情報が表示されます：

1. **Parameters（プロンプト）**
   - 画像を生成する際に使用されたプロンプト
   - 複数行で表示される場合があります

2. **Negative Prompt（ネガティブプロンプト）**
   - 生成時に除外されたプロンプト

3. **Steps（学習パラメータ）**
   - Steps、CFG Scale、Sampler、Model など
   - キー・値のペアで表示

#### テキスト/グリッド表示の切替

- 各セクションのトグルボタンをクリック
- **グリッド表示**（デフォルト）：行番号付きで表示
- **テキスト表示**：テキストのまま表示

#### クリップボードにコピー

- グリッド表示モードでセルをクリック
- テキスト表示では「コピー」ボタンをクリック
- コピーしたテキストを他のアプリケーションに貼り付け可能

### フィルター機能

- 右側のフィルターボックスにプロンプト内容を入力
- 現在のフォルダ内で、プロンプトに一致する画像を抽出
- `Clear` ボタンでフィルターをクリア

### お気に入い機能

#### お気に入いに追加

1. 画像を表示
2. 右側の `[★]` ボタンをクリック
3. ポップアップで `[ブックマークに追加]` ボタンをクリック

#### お気に入い一覧の表示・開き方

1. `[★]` ボタンをクリック
2. ポップアップの一覧から画像をシングルクリックで開く

#### お気に入いの詳細

- **追加日時**: 各お気に入いには追加日時が「yyyy/MM/dd HH:mm:ss」形式で表示されます
- **表示順序**: 最新に追加したお気に入いが一番上に表示（新しい順）
- **削除ボタン**: リストの右側の「×」ボタンで個別削除可能

#### お気に入いの管理

- **一括削除**: ポップアップの `[すべてのブックマークを削除]` ボタン
- **ファイルの確認**:
  - 保存先: `%AppData%\StableSatoViewer\favorites.json`
  - JSON 形式で、ファイルパス、ファイル名、追加日時が記録されます

### 履歴機能

#### 履歴の表示・開き方

1. 左側の履歴アイコンボタンをクリック
2. ポップアップの一覧から画像をシングルクリックで開く

#### 履歴の動作

- **重複判定**: 最新の履歴と同じファイルを開いた場合、新しく追加するのではなく、開いた日時のみ更新
- **開いた日時**: 各履歴に「開いた日時」が「yyyy/MM/dd HH:mm:ss」形式で表示
- **表示順序**: 最新に開いたものが一番上に表示（新しい順）

#### 履歴の削除

- リストの右側の「×」ボタンで個別削除可能
- `[履歴をすべてクリア]` ボタンですべての履歴を削除

#### 履歴ファイル

- 保存先: `%AppData%\StableSatoViewer\history.json`
- JSON 形式で保存

### その他の機能

#### 画像の削除

- `Delete` キーを押す
- 確認ダイアログで `Yes` を選択
- 画像はゴミ箱に移動されます（完全削除ではありません）

#### エクスプローラーで開く

- 右側の `[Open in Explorer]` ボタンをクリック
- 現在の画像をエクスプローラーで選択状態で表示

#### フォルダツリーの表示切替

- 左側の `[Tree]` ボタンでフォルダツリーの表示/非表示を切り替え

#### 全画面表示

- 右側の `[Full Screen]` ボタンで全画面モードに切り替え
- `Esc` キーで全画面を解除

## キーボードショートカット

| キー | 機能 |
|------|------|
| `左` | 前の画像（フォルダの先頭で前のフォルダへ移動） |
| `右` | 次の画像（フォルダの最後で次のフォルダへ移動） |
| `Delete` | 画像をゴミ箱へ移動 |
| `Esc` | 全画面モード終了 |

## 設定ファイル

アプリケーションの状態は以下のディレクトリに保存されます：

```
%AppData%\StableSatoViewer\
├─ windowstate.json    # ウィンドウサイズ、位置、レイアウトモード
├─ favorites.json      # お気に入いのリスト（JSON形式）
├─ history.json        # 履歴（JSON形式）
├─ lastfolder.txt      # 最後に選択したフォルダ
└─ lastimage.txt       # 最後に表示した画像
```

これらのファイルを削除すると、初回起動時にリセットされます。

## トラブルシューティング

### 画像が表示されない

- PNG ファイルであることを確認
- ファイルが破損していないか確認
- フィルターが適用されていないか確認（`Clear` ボタンをクリック）

### メタデータが表示されない

- Stable Diffusion (AUTOMATIC1111/Forge など) で生成された PNG のみ対応
- tEXt/iTXt チャンクに "parameters" キーを含む必要があります

### 画像を削除できない

- ファイルが他のアプリケーションで開かれていないか確認
- 読み取り専用ファイルになっていないか確認
- 管理者権限を試してみてください

### ウィンドウの位置がおかしい

- `%AppData%\StableSatoViewer\windowstate.json` を削除して再起動
