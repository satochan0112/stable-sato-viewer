# Stable Sato Viewer

**Stable Sato Viewer** は、Stable Diffusion で生成された PNG 画像のメタデータ（プロンプト、ネガティブプロンプト、生成パラメータ）を表示・管理するための Windows デスクトップアプリケーションです。

![Stable Sato Viewer](PngViewer/Assets/stablesatoviewer.png)

## 主な機能

- ?? **フォルダツリー表示** - ドライブ全体を階層的に表示し、フォルダ間を簡単に移動
- ??? **画像ビューア** - PNG 画像の高速表示と閲覧
- ?? **メタデータ表示** - PNG の tEXt/iTXt チャンクから以下を抽出・表示
  - プロンプト（Parameters）
  - ネガティブプロンプト（Negative Prompt）
  - 生成パラメータ（Steps、CFG Scale、Sampler など）
- ?? **フィルター機能** - プロンプトの内容で画像を検索・絞り込み
- ? **お気に入り管理** - よく使う画像をブックマーク
- ?? **複数のレイアウトモード** - 用途に応じた表示切替
- ?? **クリップボードコピー** - セルをクリックでテキストをコピー
- ??? **ゴミ箱削除** - 不要な画像を安全に削除
- ?? **状態保存** - ウィンドウサイズ、位置、最後に開いた画像を記憶

## システム要件

- **OS**: Windows 10/11
- **.NET**: .NET 10.0 ランタイム
- **その他**: WPF 対応環境

## インストール

### リリース版（推奨）

1. [Releases](https://github.com/satochan0112/stable-sato-viewer/releases) から最新版をダウンロード
2. ZIP ファイルを解凍
3. `StableSatoViewer.exe` を実行

```bash
git clone https://github.com/satochan0112/stable-sato-viewer.git
cd stable-sato-viewer/PngViewer
dotnet build -c Release
```

## 使い方

### 基本操作

#### 画像を開く

1. **フォルダツリーから選択**
   - 左側のフォルダツリーでフォルダを展開
   - フォルダをクリックすると、そのフォルダ内の PNG 画像が読み込まれます
   - ファイルリストから画像をダブルクリックで表示

2. **ドラッグ＆ドロップ**
   - PNG ファイルを画像表示エリアにドラッグ＆ドロップ

3. **コマンドライン引数**
   ```bash
   StableSatoViewer.exe "C:\path\to\image.png"
   ```

#### 画像の切り替え

| 操作 | 動作 |
|------|------|
| `←` / `→` キー | 前の画像 / 次の画像 |
| マウスサイドボタン | XButton1（戻る）/ XButton2（進む）で画像切り替え |
| ファイルリストで選択 | クリックで画像を表示 |
| フォルダの境界で `←` / `→` | 前後のフォルダへ自動移動 |

### メタデータの表示

画像を開くと、右側のパネルに以下の情報が表示されます：

1. **Parameters（プロンプト）**
   - 画像生成に使用されたプロンプト
   - 各行がカンマ区切りで表示されます

2. **Negative Prompt（ネガティブプロンプト）**
   - 除外したい要素のプロンプト

3. **Steps（生成パラメータ）**
   - Steps、CFG Scale、Sampler、Model など
   - キー：値 の形式で表示

#### テキスト/グリッド表示の切り替え

- 各セクションのヘッダー横にあるトグルボタンをクリック
- **グリッド表示**: 行ごとに整形された表示（デフォルト）
- **テキスト表示**: 生テキストをそのまま表示

#### クリップボードにコピー

- グリッド表示モードで、セル上でクリック
- セルの内容がクリップボードにコピーされます
- トースト通知で「Copied to clipboard!」と表示

### レイアウトモード

右上の `[表示切替]` ボタンで 3 つのモードを切り替え：

| モード | 説明 |
|--------|------|
| **0: 通常** | 左：フォルダツリー、中央：画像、右：メタデータパネル |
| **1: フロート** | 画像を最大化、プロンプトをフローティング表示 |
| **2: 非表示** | 画像のみ表示（メタデータパネル非表示） |

### フィルター機能

プロンプトの内容で画像を検索できます：

1. 右上の「Filter」テキストボックスにキーワードを入力
2. `Enter` キーを押すか `[Filter]` ボタンをクリック
3. プロンプト（Negative Prompt より前の部分）に一致する画像のみ表示
4. `[Clear]` ボタンでフィルターを解除

**例**：
- `masterpiece` → "masterpiece" を含む画像のみ表示
- `1girl` → "1girl" を含む画像のみ表示

### お気に入り機能

#### お気に入りに追加

1. 画像を表示
2. 右上の `[★]` ボタンをクリック
3. ポップアップで `[Add Current]` をクリック

#### お気に入りを表示

1. `[★]` ボタンをクリック
2. リストから画像をダブルクリック

#### お気に入りの管理

- **すべて削除**: ポップアップ内の `[Remove All]` ボタン
- **手動編集**: `[Edit Favorites]` ボタンでファイルを開く
  - 保存場所: `%AppData%\StableSatoViewer\favorites.txt`
  - 1行1パスでテキストファイルとして編集可能

### その他の機能

#### 画像の削除

- `Delete` キーを押す
- 確認ダイアログで `Yes` を選択
- 画像はゴミ箱に移動されます（完全削除ではありません）

#### エクスプローラーで開く

- 右上の `[Open in Explorer]` ボタンをクリック
- 現在の画像がエクスプローラーで選択状態で表示されます

#### フォルダツリーの表示切替

- 右上の `[Tree]` ボタンでフォルダツリーの表示/非表示を切り替え

#### 全画面表示

- 右上の `[Full Screen]` ボタンで全画面モードに切り替え
- `Esc` キーで全画面を解除

## キーボードショートカット

| キー | 動作 |
|------|------|
| `←` | 前の画像（フォルダの先頭で前のフォルダへ移動） |
| `→` | 次の画像（フォルダの末尾で次のフォルダへ移動） |
| `Delete` | 画像をゴミ箱に移動 |
| `Esc` | 全画面モード解除 |
| `Enter`（フィルターボックス） | フィルター実行 |

※ テキストボックスやグリッドにフォーカスがある場合でも、`←` / `→` キーで画像を切り替えできます

## 設定ファイル

アプリケーションの状態は以下のディレクトリに保存されます：

```
%AppData%\StableSatoViewer\
├── windowstate.json    # ウィンドウサイズ、位置、レイアウトモード
├── favorites.txt       # お気に入りリスト
├── lastfolder.txt      # 最後に選択したフォルダ
└── lastimage.txt       # 最後に表示した画像
```

これらのファイルを削除すると、初期状態にリセットされます。

## トラブルシューティング

### 画像が表示されない

- PNG ファイルであることを確認
- ファイルが破損していないか確認
- フィルターが適用されていないか確認（Clear ボタンをクリック）

### メタデータが表示されない

- Stable Diffusion (AUTOMATIC1111/Forge など) で生成された PNG のみ対応
- tEXt/iTXt チャンクに "parameters" キーが含まれている必要があります

### 画像を削除できない

- ファイルが他のアプリケーションで開かれていないか確認
- 読み取り専用属性がついていないか確認
- 管理者権限で実行してみる

### ウィンドウの位置がおかしい

- `%AppData%\StableSatoViewer\windowstate.json` を削除して再起動
